# 圣农集团 AI 零售销售作战中枢（企业命题大赛作品）

## 项目简介

本项目为“AI 先锋未来人才大赛”企业命题参赛作品。针对某头部农牧企业在 B 端销售中面临的“数据散落、决策滞后、一线赋能弱”等核心痛点，设计并开发了一套基于 Vue3 与 ECharts 的三级联动智能决策平台前端原型。

系统以“事找人”为核心设计理念，覆盖从一线业务员到集团高管的全链路业务闭环，并通过深度集成飞书生态（多维表格双向同步），实现数据的实时流转与沉淀。

## 核心功能模块

系统采用 L1 员工、L2 主管、L3 高层三级权限分层设计，不同身份登录后呈现差异化功能界面。

### L1 员工端（一线感知层）
- **AI 助手（天启）**：支持角色感知的智能问答，覆盖产品规格、价格政策、退换货等高频业务场景。
- **数据上传**：支持文件、图片及语音上传，模拟 AI 自动识别与语音转写，自动生成拜访记录。
- **工作台与报表**：提供目标完成率环形进度卡、待办事项勾选，并支持一键生成包含业务跟进的 AI 日报。

### L2 主管端（区域预警层）
- **异常工单处理（核心）**：设计并实现“待处理 - 处理中 - 已处理 / 无法处理”的 4 状态业务闭环。卡片附带严重程度标签与 AI 处置建议，支持处置时间线与修改方案归档。
- **区域经营看板**：由数据源驱动的核心 KPI 卡（销售额、团队人数、异常处理率等）与区域销售趋势图。
- **团队与 AI 辅助**：提供团队业绩排行榜（金/银/铜徽章）；支持天启 AI 针对区域态势自动生成竞品汇总、大客户挽留话术及促销邮件草稿。

### L3 高层端（集团决策层）
- **战况仪表盘**：集团级 KPI 卡与异常处理健康度环形图。
- **AI 预测趋势线**：基于历史数据，通过“移动平均 + 线性外推”算法实时计算斜率，生成带有置信区间带的预测趋势线，拒绝静态死数据。
- **全域视角与工单穿透**：10 大区域实时排名（比例抖动特效）；支持点击区域穿透至异常明细列表，并查看责任主管与工单时间线。

## 技术架构与项目特色

- **前端框架**：Vue 3.4 + Vite 5.4 + Element Plus 2.8 + ECharts 5.5 + Vue Router 4.3。
- **数据架构（全 Mock 零后端）**：约 1300 行 Mock 数据集中管理，实现“模拟数据源 + 真实计算逻辑”的第三类标准。
- **AI 辅助开发（Vibe Coding 实践）**：项目高度依赖 AI 辅助编程完成代码落地。通过自然语言驱动，快速实现了 12 个页面的复杂交互，展现了极强的需求拆解与工程落地能力。
- **飞书生态数据协同**：内建 API 接口对接飞书多维表格（Base）。前端在工单状态流转（如点击“已处理”）时，可实时写回云端 Base 数据库，实现前后端数据的双向同步。
- **本地规则引擎**：在无真实 LLM 依赖的情况下，基于关键词匹配与本地知识库，实现了具备角色感知能力的 AI 助手对话分支。
